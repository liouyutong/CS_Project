# 虛旅語境 (CS_Project)

本專案以樹狀結構呈現主要資料夾與內容，方便快速了解各部分用途。

## 專案結構

```text
虛旅語境/
├── README.md                  # 專案說明文件
├── 口頭報告_初賽.mp4         # 口頭報告影片檔案
├── 報告相關/                 # 存放專題報告、簡報與相關文件
│   ├── 專題海報.pdf
│   ├── 專題簡報_初賽完整版.pptx
│   ├── 專題簡報_完整版PDF.pdf
│   ├── 專題簡報_決賽刪減版.pptx
│   └── 書面報告.pdf
├── 遊戲_相關資源/             # 存放遊戲所需的素材與輔助檔案
│   ├── animation/            # 動畫檔案，例如角色動作 FBX
│   ├── app.py/               # Python 程式與資料庫檔案
│   │   ├── app.py
│   │   └── memory_db.json
│   ├── background/           # 背景影片與場景素材
│   ├── clothes/              # 角色服裝模型與相關檔案
│   ├── female/               # 女性角色模型與貼圖資源
│   ├── hair/                 # 髮型模型與材質貼圖資源
│   ├── male/                 # 男性角色模型與貼圖資源
│   └── word/                 # 文字內容、字型與對話相關檔案
└── 遊戲_虛旅語境/            # Unity 專案主體
    ├── .plastic/             # Unity 版本控制與環境設定資料
    ├── Assets/               # 遊戲場景、腳本、素材與 UI 資源
    ├── Packages/             # Unity 套件設定
    ├── ProjectSettings/      # 專案設定檔
    ├── UserSettings/         # 使用者與編輯器設定
    ├── .vsconfig             # Visual Studio 設定檔
    └── ignore.conf           # 版本控制忽略設定檔
```

## 說明

- `報告相關/` 主要用來存放專題報告與簡報資料。
- `遊戲_相關資源/` 包含角色、動作、背景與其他素材檔案。
- `遊戲_虛旅語境/` 是 Unity 專案的核心資料夾，包含遊戲開發所需的主要內容。
